# 纸桌 · Paper Desk（原型）

把待办、便签、卡册、小票统一成「一切都是纸」的桌面工具。先做网页原型确认手感，之后搬进 Tauri。

在线：https://solomenn.github.io/paper-desk/

## 桌子（index.html）

米色桌面，从左边开始往右一直延伸。拖空白处移动（带惯性），东西放得越远桌面越长；`Ctrl` + 滚轮或工具栏缩放；双击空白回到开头。

| | 用来 | 操作 |
|---|---|---|
| **今日卡**（一张） | 今天要勾的小事；背面是今天的随手记（小票底部那句就印它的第一行） | 点方框打勾，点文字直接改，回车在下面加一条，空行退格删除；`Tab` / `Shift+Tab` 或右键设为子任务 / 主任务，主任务显示自己的子任务进度。悬停一行出现左侧把手，拖动可排序，往右拖变子任务、往左拖变主任务，主任务带着子任务一起走。没勾的留到第二天 |
| **项目卡**（可多张） | 正面：目标 + 完成条件；背面是明信片：横线随手记、邮票框、邮戳样式的计时（拖动设分钟，点中间开始/暂停），底部记着起始日期、专注次数和分钟 | 卡片右下角鼠标变成小手，点一下或拖动就翻面：卡片跟着手 3D 翻转、带光泽和回弹，停下后回到平面；勾完出现「盖章」，邮票盖进背面的邮票框，然后收进卡册；右键可扔掉 |
| **便签** | 备忘，字多了自动往下长 | 从工具栏拖出；拖动不转；拖图钉按上去就固定，拖走图钉才能再动；四角外侧小点或滚轮调角度；双击写字，右键换色 |

卡片和事项都有右键菜单（编辑、加子任务、完成、翻面、收起、扔掉…）。配色：米色纸 + 绿色点缀，红色只用在盖章。

两种卡和便签都一样：拖到屏幕右边就收成边缘标签，悬停偷看，点一下拿回；拖着便签时下方出现圆圈，拖进去扔掉。

工具栏：今日 · 新建项目 ｜ 四本便签本 · 图钉 ｜ 收起所有便签 · 小票 · 缩放 · 帮助 ｜ ‹ 收到左边（左边缘留一张小纸片，点它拿回来）。右下角的本子是卡册。

## 手账（journal.html）

工具栏里那本绿色小书打开。一个书架，每个月一本手账（今年到现在的每个月都在架上，有记录的更厚，本月那本挂着书签带）。

- 悬停书脊：书往上提一点；点击：书被勾出来、转过来露出封面、移到面前，硬封面翻开（几乎不弯）
- 第一页是月历：绿点＝勾过事，红印＝项目盖章，黄块＝便利贴，短线＝碎碎念；点有记录的日子直接翻过去
- 之后每天一页：上面是当天做过的清单（盖章的项目加粗、行尾一枚小红章，然后是勾过/没勾的事），虚线下面是碎碎念的横线（可直接写，和今日卡背面是同一份），当天写的便利贴用纸胶带贴在右下角
- 翻页同卡册（拖页边、点页边、方向键）；`Esc` 或左上角合上，书缩回书架原位

## 卡册（album.html）

点右下角那本「卡册」打开。盖过章的项目卡一页 4 张；拖着纸页边缘翻（[paper-flipbook](https://github.com/JohnnyWang8802/paper-flipbook) 的 CSS 条带翻页，MIT），点卡片拿出来、再点翻到背面，能看到当时的随手记和专注记录。

## 今日小票（receipt.html）

桌子工具栏 `⎙` 打开。基于自己做的「日程进度打印机」（LIFE POS），打印今日卡上的事和今天盖过章的项目：勾了的 `OK`（打勾时间），没勾的 `··`。EDIT 面板里「今天的桌子」可重新导入。

## 存档（localStorage）

| key | 内容 |
|---|---|
| `paper-desk.today.v1` / `paper-desk.todaycard.v1` | 今日卡的事项 / 位置与是否收起 |
| `paper-desk.desk-tasks.v1` | 项目卡（位置、是否收起）+ 盖过章的项目卡（卡册） |
| `paper-desk.todaymemo.v1` | 每天的碎碎念（今日卡背面 / 手账） |
| `paper-desk.mat.v2` | 桌面平移位置、缩放、布的长度 |
| `paper-desk.memos.v1` | 便利贴 |
