# 纸桌 · Paper Desk（原型）

把待办、便签、卡册、小票统一成「一切都是纸」的桌面工具。先做网页原型确认手感，之后搬进 Tauri。

在线：https://solomenn.github.io/paper-desk/

## 桌子（index.html）

一张桌子上放三样东西，各管各的：

| | 是什么 | 怎么用 |
|---|---|---|
| **今日清单**（左） | 今天要做完的事，有进度 | 底部输入框回车添加；点方框直接打勾；双击改字；悬停出现 `↗`（放到中间）和 `✕`（删掉）；也可以直接把一行拖到中间 |
| **当前任务**（中） | 正在专心做的那一件，只放一张 | 正面：标题、本次目标、进度；背面：完成条件 + 计时盘。点卡片或拖着左右翻面；往下拽放回清单；条件勾完盖章，清单里那一条印上「成」字小邮票，卡片进右下角「已完成」堆 |
| **便利贴**（右） | 备忘，不需要完成 | 从左下便签本撕；抓哪儿从哪儿晃；图钉钉住后绕钉子转；拖四角外侧小点或滚轮调角度；往右边缘甩成索引贴，悬停偷看、点一下抽出；`⇥` / `T` 收起所有没钉的；双击写字，右键换色 |

没做完的事会留到第二天；做完的只在完成当天显示。

## 卡册（album.html）

点「已完成」堆打开。盖过章的任务卡一页 4 张；拖着纸页边缘翻（[paper-flipbook](https://github.com/JohnnyWang8802/paper-flipbook) 的 CSS 条带翻页，MIT），点卡片拿出来、再点翻到背面。

## 今日小票（receipt.html）

桌子工具栏 `⎙` 打开。基于自己做的「日程进度打印机」（LIFE POS），打印今天的清单：做完的 `OK`（打勾时间），没做完的 `··`。EDIT 面板里「今天的桌子」可重新导入。

## 存档（localStorage）

| key | 内容 |
|---|---|
| `paper-desk.today.v1` | 今日清单 |
| `paper-desk.desk-tasks.v1` | 当前任务卡 + 盖过章的卡（卡册） |
| `paper-desk.memos.v1` | 便利贴 |
