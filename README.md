# 纸桌 · Paper Desk（原型）

把待办、便签、卡册、小票统一成「一切都是纸」的桌面工具。先做网页原型确认手感，之后搬进 Tauri。

在线：https://solomenn.github.io/paper-desk/

## 桌子（index.html）

一块铺在木桌上的布：左边是开头，往右一直铺。按住空白处拖动（或滚轮）往右挪，带惯性；便签放到右边布边，布会再往右铺开一块。`Ctrl` + 滚轮（触控板双指捏合）或底栏 `− 100% +` 缩放，点百分比回到 100%；双击空白回到开头。

底栏（木桌沿）从左到右：今日卡、项目卡（点一下拿出来或滑到它那里；没有项目卡时新建一张）、四本便签本、图钉碟、废纸篓、收起便签、打印小票、帮助、缩放。右下角是卡册（一本布面小本子，写着张数），点开就是卡册。

布上有三种纸：

| | 是什么 | 怎么用 |
|---|---|---|
| **今日卡** | 今天要勾的小事 | 点方框打勾；点文字直接改；回车到下一条/新增；空行退格删除。没勾的留到第二天，勾了的只在当天显示 |
| **项目卡** | 一个项目：本次目标 + 完成条件，背面计时 | 同样的勾选列表；↻ 或 `F` 翻到背面计时盘（拖一圈设分钟，点中间开始/暂停）。条件全勾完出现「盖章 · 收进卡册」，点了才盖章归档；之后空位点「＋ 新的项目卡」 |
| **便利贴** | 备忘，不需要完成 | 从左下便签本撕；拖动时平稳跟手不转；图钉按上去就钉死（不能挪不能转），把图钉拖下来才能再动；拖四角外侧小点或滚轮调角度；往右边缘甩成索引贴，悬停偷看、点一下抽出；`⇥` / `T` 收起所有没钉的；双击写字，右键换色 |

两张卡按住任意空白处都能挪位置；点 ≡ 收到右边缘变成白色卡签（「今日」「项目」），点卡签拿回来。

## 卡册（album.html）

点右下角那本「卡册」打开。盖过章的项目卡一页 4 张；拖着纸页边缘翻（[paper-flipbook](https://github.com/JohnnyWang8802/paper-flipbook) 的 CSS 条带翻页，MIT），点卡片拿出来、再点翻到背面。

## 今日小票（receipt.html）

桌子工具栏 `⎙` 打开。基于自己做的「日程进度打印机」（LIFE POS），打印今日卡上的事和今天盖过章的项目：勾了的 `OK`（打勾时间），没勾的 `··`。EDIT 面板里「今天的桌子」可重新导入。

## 存档（localStorage）

| key | 内容 |
|---|---|
| `paper-desk.today.v1` / `paper-desk.todaycard.v1` | 今日卡的事项 / 位置与是否收起 |
| `paper-desk.desk-tasks.v1` | 项目卡（位置、是否收起）+ 盖过章的项目卡（卡册） |
| `paper-desk.mat.v2` | 桌面平移位置、缩放、布的长度 |
| `paper-desk.memos.v1` | 便利贴 |
