# 纸桌 · Paper Desk（原型）

把待办、便签、卡册、小票统一成「一切都是纸」的桌面工具。先做网页原型确认手感，之后搬进 Tauri。

在线：https://solomenn.github.io/paper-desk/

## 桌子（index.html）

桌上只有两种纸：

| | 是什么 | 怎么用 |
|---|---|---|
| **今天的卡**（中间） | 今天要勾完的事，有进度 | 正面：标题、本次目标、完成进度、勾选列表（底部输入框回车加一条，点一下打勾，双击改字，悬停 ✕ 删）；背面：计时盘（点 ↻ 或拖着左右翻）。点 ≡ 或往下拽，收到右边缘变成一张白色卡签，点卡签拿回来。全部勾完自动盖章，进右下角「已完成」堆；空位点「＋ 新的一张」 |
| **便利贴**（四周） | 备忘，不需要完成 | 从左下便签本撕；抓哪儿从哪儿晃；图钉钉住后绕钉子转；拖四角外侧小点或滚轮调角度；往右边缘甩成索引贴，悬停偷看、点一下抽出；`⇥` / `T` 收起所有没钉的；双击写字，右键换色 |

## 卡册（album.html）

点「已完成」堆打开。盖过章的任务卡一页 4 张；拖着纸页边缘翻（[paper-flipbook](https://github.com/JohnnyWang8802/paper-flipbook) 的 CSS 条带翻页，MIT），点卡片拿出来、再点翻到背面。

## 今日小票（receipt.html）

桌子工具栏 `⎙` 打开。基于自己做的「日程进度打印机」（LIFE POS），打印今天卡上的事（以及今天盖过章的卡）：勾了的 `OK`（打勾时间），没勾的 `··`。EDIT 面板里「今天的桌子」可重新导入。

## 存档（localStorage）

| key | 内容 |
|---|---|
| `paper-desk.desk-tasks.v1` | 今天的卡（是否收起）+ 盖过章的卡（卡册） |
| `paper-desk.memos.v1` | 便利贴 |
