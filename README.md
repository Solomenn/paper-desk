# 纸桌 · Paper Desk（原型）

把待办、便签、卡册、小票统一成「一切都是纸」的桌面工具。这里先放交互原型，确认手感后再搬进 Tauri。

入口：`index.html`。在线：https://solomenn.github.io/paper-desk/

## desk.html · 桌子（主入口）

便利贴和当前任务合在一张桌子上：

| 操作 | 效果 |
|---|---|
| 把便签拖到中间的「当前任务」卡位 | 便签变成任务卡：第一行是标题，其余是本次目标。没有条件时自动翻到背面让你写 |
| 再拖一张进来 | 中间永远只有一张；原来那张退回成便签甩到左边，条件和计时都跟着它，下次拖回来还在 |
| 抓住卡片往下拽 | 放回去，变回便签 |
| 勾完所有条件 | 盖章，卡片飞进右下角「已完成」堆（之后接卡册和小票） |

其余便利贴、任务卡操作同下。存档：`paper-desk.desk.v1`（便签）、`paper-desk.desk-tasks.v1`（任务）。

## receipt.html · 今日小票

桌子左下角工具栏里的 `⎙` 打开。基于自己做的「日程进度打印机」（LIFE POS），换成纸桌配色：

- 打开时自动读取桌子上**今天**盖过章的卡（按盖章时间排，`OK`），中间还在做的那张记为 `··`
- EDIT 面板里多了一个预设「今天的桌子」，随时重新导入；其余编辑、PRINT 导出 PNG 都和原来一样
- 今天还没有盖章的卡时，沿用上次保存的小票内容

## album.html · 卡册

桌子右下角「已完成」堆点一下就打开。读取桌子上盖过章的卡片（`paper-desk.desk-tasks.v1`），一页 4 张；还没有完成的卡片时显示示例。

| 操作 | 效果 |
|---|---|
| 拖住纸页边缘往另一边拉 | 纸跟着手弯过去，松手按位置和速度决定翻不翻 |
| 点页边空白 / `←` `→` / 空格 | 翻页；`Home` `End` 到首尾 |
| 鼠标靠近外侧页边 | 页角微微掀起 |
| 点卡片 | 拿出来放大；再点翻到背面看完成条件；点外面或 `Esc` 放回 |

翻页用的是 [paper-flipbook](https://github.com/JohnnyWang8802/paper-flipbook)（MIT）的 CSS 条带翻页模型：一页切成 14 条，越靠外缘越滞后，逐条着色并在下面那页投影。

## task-card.html · 当前任务

主战场只留一张卡，其他留在左边的待办堆里。

| 操作 | 效果 |
|---|---|
| 单击卡片空白处 / 拖着卡片左右翻 / `F` / 空格 | 翻面。拖动时卡片跟手转，松手按速度决定翻不翻过去 |
| 正面 | 标题、本次目标、完成进度 |
| 背面 | 完成条件（点一下勾选）+ 计时盘 |
| 计时盘 | 红色圆盘就是剩下的时间（一圈 = 60 分钟）。绕圈拖动设分钟，点中间开始 / 暂停，到点轻响两声 |
| 条件全部勾完 | 翻回正面、盖邮票和邮戳，1.5 秒后卡片飞进右边「已完成」，待办堆顶上那张自动发上来 |
| 点左边待办堆 | 换上第一张；当前那张回到待办堆底 |
| `+` | 新任务 |
| 双击任何文字 | 编辑；回车或 Esc 结束（目标里回车换行） |

存档：`localStorage`，key `paper-desk.tasks.v1`。

## sticky-desk.html · 便利贴

双击打开即可，零依赖、离线、`localStorage` 存档（key：`paper-desk.sticky.v1`）。

| 操作 | 效果 |
|---|---|
| 从左下便签本拖出 | 撕下一张新便签；单击便签本则直接落一张到桌上并进入编辑 |
| 抓住便签任意位置拖动 | 抓哪儿就从哪儿悬着：受重力和手的加速度摆动，松手会带着速度滑一小段，按上去时略微扶正 |
| 从小碟里拖图钉按到便签上 | 钉住。钉住的便签拖动时只会绕钉子转；用力扯（离钉子约 270px）会把钉子扯飞 |
| 拖便签上的图钉 | 拔下来 |
| 往右边缘一甩 / 拖进边缘 | 收成索引贴，按颜色分组 |
| 悬停索引贴 | 便签从边缘探出半张偷看；移开自动缩回 |
| 点索引贴 / 拖索引贴 | 抽出来放在边缘旁 / 直接抽到手上 |
| `⇥` 或 `T` | 所有没钉住的便签一起收进边缘（钉住的留在桌上） |
| 双击 | 写字　右键：换颜色（分类）/ 扔掉　拖进废纸篓：扔掉 |

### 物理模型

拖动时便签是一张以抓取点为支点的刚性纸片：

```
τ = r × (重力 − 手的加速度) − 纸的抗扭刚度 · (θ − θ₀)
```

再加上角阻尼。参数在脚本顶部（`G`、`KS`、`DAMP`、`KACC`、`KR`、`CR`、`YANK`）。阴影按屏幕空间的光源方向计算，不随便签旋转；抬起程度（`--lift`）同时驱动下沿翘起、阴影变大变软。

### 迁到 Tauri 时

- 每条屏幕边缘一个透明置顶细长窗口承载全部索引贴；抽出的便签才单独开窗口
- 物理与渲染逻辑可原样复用，只把「桌面坐标」换成屏幕坐标
