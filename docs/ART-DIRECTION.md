# 纸桌 · 美术方向（初稿）

第三阶段的文档（见 `HANDOFF.md` 第八节）。写法照 sasshi 的 `prompts/build/art-direction.md`：先定一个房间、一天里的一个时刻、一束光，颜色、字体、版式、控件、动效和禁止项都从它推出来。每一条后面写了理由。四项待定的已经全部由用户定下（见第十节）。

依据：用户已确认的选择（`HANDOFF.md`、`README.md`）、已上线的两项复现（`lab/window-light.html` 窗光、`lab/strip.html` 切换条），以及 T3 收音机（`radio.html`，质量和风格基准）。

## 一、场景：一个房间、一个时刻、一束光

**白天，一间浅灰白的房间。太阳从左边一扇百叶窗照进来，一道道百叶的影子斜落在墙上和物件上。** 七个物件在这束光里站成一排，就是纸桌的入口。

- **光源**：一个太阳。方位 35°、高度 32°，从画面左上方来；太阳有大小，视直径约 0.86°，所以影子边缘是软的。数值来自窗光复现（`assets/objects/lintex-light-gobo.json`），按 LINTEX Silk Wall 产品图拟合。
  - 理由：这束光是用户坚持要加的；已经按原图逐项验收（21 项过 20 项），不再另起一套。
- **窗**：左侧一面看不见的墙上的一扇百叶窗（2026-11-02 起，原来是三扇半圆拱窗），中间一根竖拉绳。它只用来投影子，画面里看不到窗本身。其他页面的背景墙也是这面墙（`room.js`）。
  - 理由：和 sasshi 同一种做法（窗框和树枝是看不见的遮挡物），影子是真投下来的，不是贴上去的光斑。
- **时刻**：默认是上午的冷调日光（天光偏青、阳光纯白；用户 2026-11-02 定）；另有一档暖调（阳光 `#fff0dc`），是同一间房的下午。右下角两个色点切换，和窗光实验页一样。
  - 理由：用户说两种都喜欢，都要留。一次只出现一个时刻，光的方向不变，只换色温。
- **夜晚**：不在这份文档里。用户要的白天/夜晚两套主题以后另写一份，到时也是"一个房间、一个时刻、一束光"，光源换成室内灯。
- **雪国线**：计时页里的像素风车厢是一个独立的画中世界，不受本文档的光和色约束（用户定过：像素风只用在雪国线行程里）。

## 二、颜色

色名取中国传统色，色值是纸桌自己的，从已有场景里量出来或沿用，不照搬色名对应的标准色值。界面只用下面这一组；物件自己的颜色另列，不混进界面色板。

| 名 | 色值 | 用途 |
|---|---|---|
| 霜 | `#e6e9eb` | 房间底色（冷调）；3D 画布透明，铺在它上面。暖调时换成 `#ebe8e3` |
| 素 | `#f0f0ee` | 墙面、大面积的纸 |
| 缟 | `#f7f7f5` | 浮起的面：弹出的单张、文字版 |
| 墨 | `#1a1a1a` | 名字、当前项、刻度、数值 |
| 黛 | `#3d4246` | 正文 |
| 苍 | `#8a8a8a` | 日期、标签、图标的默认色 |
| 银 | `#c9ced1` | 细线 |
| 淡墨 | `#b5b9bc` | 不可用状态、装饰性的点，不承载意义 |
| 蓝莓（强调色） | `#647F98` | 唯一的强调色：切换条上的指针、细调轮当前格、焦点框。取自 Forbo Bulletin Board「Blue Berry 2214」 |

- **只有一个强调色：Blue Berry 2214**（用户 2026-11-02 定）。它替换切换条复现里的橙色 `#ff9500`，第四阶段换。色值是从色卡截图取的屏幕近似值，不是厂家公布的精确值。在房间底色上的对比度约 3.4:1（墙面上 3.7:1），够做指针和焦点框（非文字元素要求 3:1），不用作正文文字色。
- **阴影带色板的色相**：用蓝黑 `rgb(14 20 24)`（窗光复现里板缝阴影的颜色），不用纯黑，也不用暖黑。
- **暖色只出现在物件和光里**（暖调阳光、书脊、照片），不出现在界面文字和控件上。

## 三、字体

最多三款，各司其职：

| 角色 | 字体 | 用在哪里 |
|---|---|---|
| 印刷体·拉丁和数字 | Sunghyun Sans（SIL OFL 1.1，已在 `assets/fonts/`） | 所有拉丁字母和数字，任何语言下都长一个样 |
| 印刷体·中文 | Noto Sans SC（SIL OFL 1.1） | 中文界面文字和正文 |
| 手写体 | 霞鹜文楷 LXGW WenKai（SIL OFL 1.1） | **只用于用户自己写的东西**：手账、便签、卡片上的字 |

- **字号**：只用四档：12（注脚、署名）、15（正文、刻度区）、17（细调轮，SemiBold）、20（日期、名字）。
- **字重**：500，强调用 600，不用粗体。
- **规则**：
  - 不用斜体；不用全大写来强调。细调轮里的月份缩写（JAN、FEB…）是复现原站，算例外。
  - 数字一律等宽（`tabular-nums`）。
  - 中文字体切片只在页面用到中文时才加载。
- **不再用衬线体（思源宋体 / Noto Serif SC）**（用户 2026-11-02 定）。现在各页的标题用的是衬线体，第四阶段改掉。
  - 理由：用户要求全站一套字体，界面用印刷体、手写体只给用户写的字；T3 的文字小而细，只有一种无衬线体。一套无衬线体加一套手写体，比三套更克制。

## 四、版式

**入口（切换条）**：沿用复现页的实测尺寸，不随窗口缩放。

- **物件**：每格宽 240，格距 272，物件区 240 × 240。
- **文字**：物件上方是日期，20 号字、苍色。**物件下面不放页名**（用户 2026-11-02 定），让物件自己说明是哪一页。
- **刻度区**：544 × 104，水平居中。竖直位置按窗口高度在 7 个实测点之间插值（`lab/strip.html` 的 `place()`）。
- **物件间距**：七个物件各占一格，按真实尺寸的比例摆，不硬塞成同样大小。
- **宽屏（2560）**：尺寸不变，左右留白变多；只有七个物件，不复制填充。
- **手机（390 × 844）**：暂不做，桌面版定稿后再说（用户 2026-11-02 定）。

**进入一页（详情视图）**：物件本身就是界面。

- 物件放大到画面中央，占画面高度约 70%。光和房间不变，相机推近。
- 没有标题栏、侧栏和卡片。返回入口：左上角一个图标，或按 Esc。
- 页面自己的内容写在物件上（板上的卡片、书架上的书、小票上的字），不另起面板。

## 五、控件

- 只用图标，不配文字说明（用户偏好：让版式自己说明，不加多余的副标签）。
- 图标是 20 px 的细线图标：默认苍色，悬停变墨色，当前项用强调色。
- 控件不放在容器里：没有圆底、胶囊、托盘和毛玻璃。
- 焦点框是 2 px 强调色，离控件 3 px。
- 可调的东西尽量做在物件上：T3 转调谐盘换台、刻度条拖动换页，不另做滑块和按钮。

理由：T3 的"功能部件本身构成视觉图案"；pengzhe 的切换条本身就是导航。

## 六、光与动效

**光**

- 场景里只有一个太阳。所有物件都投真影子到墙或地面上，影子带蓝黑色相、边缘随距离变软。
- 窗格影子横过整排物件，物件动时影子留在原地，物件从影子下移过。
- 文字不被光打到：日期、名字和刻度区在光之外，或者光在那里淡掉（sasshi 的 lightFade 做法）。
- 现在 `room.js` 的平面窗形光斑和窗格影子是贴上去的，第四阶段由这束真光替代。

**动效**

- **会动的只有这些**：切换条滑行，以及日期翻动、刻度起伏和咔声（都按实测）；物件被操作时的反应（T3 调谐盘、活页夹开合）；进出详情视图时相机的推拉。
- **没有一直循环的动画**；没有东西在动时不渲染（`HANDOFF.md`：同一时间只用一个 WebGL 场景）。
- 3D 画布上不叠混合图层，不用 `backdrop-filter`。
- 开启"减少动态效果"时：滑行改为瞬移，日期不翻动，相机直接切换；物件照常显示，声音照常。

## 七、禁止项

- 复古、做旧、磨损、乡村风；旧教室、旧办公室式的木框办公用品（`HANDOFF.md` 明确排除）。
- 用 CSS 或矢量手画的物件；看起来像 AI 生成的图。
- 雪国线行程以外的像素风。
- 胶囊按钮、毛玻璃、卡片面板、装饰性渐变、表情符号。
- 纯黑阴影；第二个强调色。
- 多余的副标签和说明文字；能用图标的地方用了文字。
- 斜体；永远循环的动画；叠在 3D 画布上的混合图层。
- 照抄 pengzhe 的代码或他的建筑立面图（站点不开源，只能观察、测量、自己写）。
