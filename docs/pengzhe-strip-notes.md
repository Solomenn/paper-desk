# pengzhe 切换条实测笔记（第二阶段）

参考：<https://www.pengzhe.ng/c/2026-02-16-uncle-cha-fusion-cafe#timeline>。站点不开源，只观察和测量，自己重写，不照抄代码，也不用他的建筑图。

## 版面（1440×900，浅色）

- 物件横排，每格约 296 px 宽（中心距：128 → 424 → 720 → 1018 → 1316）。日期在物件上方（y≈230），名字和作者在下方（y≈573、605）。当前物件居中。
- 刻度区 `.tl-zone`：544×104，x=448..992，y=714..818。
- 刻度：149 根，3×8 px，圆角，颜色 #1a1a1a。不亮的透明度 0.14，当前位置附近的亮起（透明度 1）。间距约 7.29 px（544 宽里排全部地点）。
- 月份分隔 `.tl-sep`：10 根，3×14 px。
- 手机（390×844）：只显示一个物件，左右各露一点邻居；日期在上（y≈190），名字和作者在下；刻度条超出屏幕两侧。

## 交互（无头浏览器实测）

- 桌面：在刻度条上按住拖动，会逐个换物件，每过一根刻度响一声咔；松手后吸附到最近的物件。
- 快甩刻度条：先冲过头，再弹回落定。
- 桌面上滚轮横向滚动：物件条原生滚动，不吸附，也没有声音。用鼠标拖物件条本身没有反应。
- 软件渲染下时间不准：一次 1.2 s 的拖动实际用了 8 s。所以位置-时间曲线要在真机上量，无头浏览器只能用来对版面和声音参数。

## 刻度的动态（从脚本常数读出，自己重写时用）

- 吸附弹簧：ω = 0.026 /ms，阻尼比 0.7，每 8 ms 一个子步；|x−目标| < 0.5 且 |v| < 0.005 视为停稳。
- 刻度随离指针的距离 d（以刻度为单位）放大：高 = 8 + 强度×(1.5 + 4.5·e^{−d²/2.2²}) + 18·max(0, 1−d)^{1.5}；宽 = 3 + max(0, 1−d)^{1.5}；亮度随之增加。像 Dock 放大。
- 亮起时用一个"弹出"弹簧（刚度 484，阻尼 22，回弹时阻尼减半）。

## 咔声（Web Audio 实时合成）

- 每种声音一段 40 ms 的样本：白噪声经 4 kHz 二阶高通，按 0.25 ms 衰减；加两个正弦共振：5.2 kHz（衰减 0.8 ms，幅度 0.6）、7.4 kHz（衰减 0.5 ms，幅度 0.4）；起音 0.1 ms，尾部 5 ms 淡出，再归一化。
- 五种：line（音高 1，衰减 1，音量 1）、month（音高 0.88，衰减 1.2，音量 1.1）、travel（1.08 / 0.8 / 0.5）、fine（1.5 / 0.7 / 0.55）、close（1.2 / 0.85 / 0.4）。
- 总音量 0.2；每次播放速度随机 ±2%；两声之间最少隔 60 ms，排队最多 250 ms。
- 实测一次拖动响了 31 声，两种样本交替（line 和 month）。

## 控制逻辑（读主脚本得到的行为，不是代码）

- 刻度条的主体是"放大镜"：鼠标悬停在刻度区（离刻度 20 px 以内）就进入"握住"状态，响一声 line。指针下的刻度放大、变亮，并显示该处地点的日期标签。
- 按住拖动 = 擦洗（scrub）：指针对准哪根刻度，物件条就滑到对应地点；每跨一根刻度响一声，跨月响 month。
- 松手时，如果物件条还在惯性滑动，就用"当前位置 + 速度×150 ms"预测落点，取最近的物件吸附过去（吸附弹簧见上）。
- 点刻度不拖 = 直接跳到那个地点（jump）。
- 键盘：←/→ 前后一个，PageUp/PageDown 按月跳，Home/End 到两头。
- 手机：刻度条宽过屏幕，触摸拖动时刻度条整体在固定中线下平移（和桌面不同）。
- 物件条本身是原生横向滚动 + 滚动吸附；在物件条上滚轮或触摸，会先取消正在进行的吸附动画。
- 修正 HANDOFF 的描述：当前位置不是"橙色刻度"。浅色主题下，当前位置附近的刻度是不透明的黑色（其余透明度 0.14）。橙色（--tl-hot）只在握住时的高亮里出现。

## 复现进度（lab/strip.html，桌面）

已对上（同一组操作两边比）：
- **版面**：物件宽 240、间距 32；日期、方块、名字的高度；刻度区位置。刻度布局：每月刻度数按地点数分配，间距 7.29 px，月界一根长分隔。静止时 59 根刻度的位置和参考完全一致。
- **悬停**：刻度以刻度区中心放大 7.2%（由点击落点反推）；指针所指地点立一根 4×32 的橙色刻度，上方显示日期；按月"握住"，越过月界一格才换月。6 个位置点击，5 个落到同一地点，剩下 1 个差一个相邻地点。
- **跳转曲线**：三次 Hermite 滑行，时长 = 460 ms + 距离×0.08，限制在 520–950 ms。逐个（键盘）380 ms，擦动 280 ms。用暂停的虚拟时钟逐帧比：两次点击的曲线逐帧吻合（912 ms 对 928 ms）。
- **咔声**：样本长度和能量分布对上（参考 4–6 kHz 占 40–51%，复现 47–55%）；每次变速 ±2%，最少间隔 60 ms。同一段匀速擦动，参考 32 声、复现 35 声，跨月声的位置一致。
- **擦动的日子**：同一天的地点合成一格（参考显示 8 18 22 23 27）。

- **粗擦和细调**：按住拖动是粗擦，样子和悬停一样（橙色刻度加日期），每跨一根刻度响一声。按住不动 500 ms，或者拖动中停下来 700 ms，就进入细调：日子轮停在指针处，刻度整体平移让当前地点对准轮心，并响一声 fine。轮上每格宽 = 字宽 + 12；月份是只占位、不能选的大写缩写；指针移动 ×0.69 转动轮子；口子贴着露出的前后各两格。用同一组连拍比，6 帧选中的日子全部一致（30 → 3 → 12 → 16 → 22 → 23）。
- **点击落点**：6 个位置全部落到同一地点。

还没对上：
- 日期标签的滚轮动画（3D 翻滚加模糊）、悬停时刻度弹出的弹簧、松手后的惯性吸附。
- 字体：参考用 Sunghyun Sans，这里用系统无衬线体。
- 细调开始时，按下后已拖过的距离带进轮子（×0.69）。只对上了一组连拍，所以限制在 ±36 px 以内。

## 第二轮（逐交互扫描，2026-11-02）

用户指出三处问题：黑色当前标记要跟着橙色走、原站每个动作都有声音、鼠标操作时刻度条有动画。补的做法如下，数值都来自暂停虚拟时钟下的逐帧实测：
- **黑色当前标记**：跟着物件条连续滑动，亮度在相邻两根刻度之间过渡。跳转时一路跟到所点的位置，每越过一根刻度响一声 travel。
- **指针靠近**（离刻度线 20–46 px）：附近几根刻度微微抬起约 2.5 px、变长、变亮。
- **悬停**：离指针最近的那根变橙、约 0.2 s 长到 33 px；指针在两格之间时，两根各长一半。两侧刻度稍稍让开，高亮比指针慢约 55 ms。点击后高亮对准所点地点，直到指针再移动 6 px。
- **悬停时的声音**：每换一个地点响一声，跨月换成 month；60 ms 内连续来的声音只保留最新一声。按下本身不出声。
- **日期标签**：月份和日子各一个轮，换字时滚动翻过去。转一次 520 ms，连续快速换字时缩短到 260 ms。
- **第三轮**：版面随窗口竖直居中（物件块以画面中线为准，刻度区在 0.75 × 高度 + 40 px），在 1280 / 1440 / 1920 / 2560 四种宽度下和参考差 0–4 px。占位方块改成与参考图框一样的 240 × 240 正方形。悬停声音改成每换一根刻度响一声，刚进入和点击对准时不响；擦动时不再叠加 travel。同一段匀速擦动，声音序列与参考完全一致（32 声，跨月位置相同）；悬停横扫 14 + 2 声与参考相同。
